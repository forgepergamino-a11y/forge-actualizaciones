# FORGE · actualizaciones

De acá baja sus versiones nuevas la app FORGE de FORGE Pergamino.

- `version.txt`: la última versión publicada, firmada con la clave de FORGE. La app no instala nada si la firma no coincide.
- `FORGE-x.y.z.exe`: el programa. Sin una licencia válida no funciona.

Para publicar una versión nueva, usar "Publicar versión de FORGE..." en FORGE Licencias, subir acá lo que deja en la carpeta `publicar` y borrar el exe anterior.
